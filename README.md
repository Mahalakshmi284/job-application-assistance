# job-application-assistance
An AI -powered job application assistant.

## Features
- Generate job-specific cover letters
- Improve resume content
- Suggest skills and keywords
- Simple and user-friendly interface

## Tech Stack
- Frontend: HTML, CSS, JavaScript
- Backend: Node.js / Python (Flask)
- AI: Generative AI API (Gemini / OpenAI)

## How It Works
1. User enters job details
2. Request is sent to backend
3. Backend calls the AI API
4. AI-generated response is shown to the user

## Setup
1. Clone the repository
2. Install dependencies
3. Add API key in environment variables
4. Run the server
5. Open the website in browser

## Future Improvements
- User login
- Resume upload
- Multiple job profiles
